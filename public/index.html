🔑 Guida: Come ottenere la tua Chiave API gratuita Apri Google AI Studio ↗
  1. Visita il portale gratuito Google AI Studio (aistudio.google.com) ed effettua l'accesso con il tuo account Google.
  2. Clicca sul pulsante blu "Create API key" (o "Get API key").
  3. Seleziona "Create API key in new project" (o scegli un progetto esistente).
  4. Copia la chiave generata (inizia con AIzaSy...) e incollala nel riquadro sopra.
  5. Clicca sul pulsante "Salva Impostazioni" in basso.
ℹ️ Nessun costo: Il piano standard di Google AI Studio include quote gratuite permanenti (Free Tier) ideali per creare schede CAA senza necessità di carta di credito.
